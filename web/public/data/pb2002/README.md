# PB2002 tectonic boundary data

`PB2002_boundaries.json` is a local snapshot of the boundary GeoJSON from
https://github.com/fraxen/tectonicplates at commit
`339b0c56563c118307b1f4542703047f5f698fae`.

Scientific source: Peter Bird (2003), “An updated digital model of plate
boundaries,” *Geochemistry, Geophysics, Geosystems*.

License: Open Data Commons Attribution License 1.0
(https://opendatacommons.org/licenses/by/1.0/), as declared by the source
repository. This is a published geological model, not a real-time measurement
of tectonic plate movement.
